# ALTA

Minicurso para una entrevista de analista de onboarding en el sector financiero argentino: KYC, AML, compliance y legajos de personas jurídicas.

Sitio: https://nicolasnb2002.github.io/alta-onboarding/

Incluye módulos desde cero, la guía de cada documento, nueve sociedades ficticias para aprobar, observar o escalar, un examen final de 35 preguntas y un oral con respuestas modelo y simulacro. El progreso queda en el navegador.

Material de estudio. Las sociedades no existen. En el puesto manda el manual del sujeto obligado y la resolución sectorial vigente.

## v2 (rama `v2-minicurso`)

- 2 módulos nuevos: enfoque basado en riesgo/matriz y Compliance/oficial de cumplimiento/listas; normativa vigente para entidades financieras (Res. UIF 14/2023 y modificatorias), etapas del lavado, sanciones, GAFI.
- 3 casos nuevos (9 en total) con documentos simulados marcados FICTICIO y filas clicables para marcar errores.
- Examen final, glosario, fuentes oficiales, ficha imprimible, ejemplos STAR y simulacro de entrevista con reloj.
- Contenido nuevo en `data2.js`; el original de `data.js` se conserva.
