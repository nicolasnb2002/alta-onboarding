# ALTA

Minicurso para una entrevista de analista de onboarding en el sector financiero argentino: KYC, AML, compliance y legajos de personas jurídicas.

Sitio: https://nicolasnb2002.github.io/alta-onboarding/

Incluye módulos desde cero, la guía de cada documento, seis sociedades ficticias para aprobar, observar o escalar, y un oral con respuestas modelo. El progreso queda en el navegador.

Material de estudio. Las sociedades no existen. En el puesto manda el manual del sujeto obligado y la resolución sectorial vigente.
